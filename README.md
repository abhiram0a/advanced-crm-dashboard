# Advanced CRM Dashboard

A responsive CRM dashboard built as a front-end development task for Greentiq Innovations Pvt. Ltd.

## Live Demo

Deployed on Vercel.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- dnd-kit

## Features

### Customer Management
- Customer list and table
- Customer details
- Add customer
- Edit customer
- Delete customer
- Update last contact date

### Search, Sorting & Pagination
- Real-time customer search
- Column sorting
- Pagination
- 10 / 25 / 50 items per page

### Advanced Filters
- Status filtering
- Company filtering
- Last-contact date range
- Phone filtering
- Email filtering
- Multiple filters
- Active filter count
- Clear all filters

### Saved Filters
- Save custom filter combinations
- Apply saved filters
- Delete saved filters
- Pre-built filter templates
- Drag-and-drop reordering
- Persistent saved-filter order

### Additional Features
- Form validation
- Toast notifications
- Loading and error states
- Debounced search
- CSV export
- Responsive desktop, tablet and mobile layouts

## Data

The project uses a mock API/service layer to simulate REST API behavior. TanStack Query is used for data fetching, caching and mutations.
